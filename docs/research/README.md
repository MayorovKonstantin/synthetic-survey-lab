# Research

Research is organized as a decision-support pipeline:

```text
question → sources → claims → concepts → synthesis → decision
```

## Required distinctions

- **Fact:** directly supported by a source or observed in the repository.
- **Interpretation:** a reasoned synthesis of facts.
- **Hypothesis:** an assumption that needs testing.
- **Decision:** an approved choice with rationale.
- **Unknown:** a material question without sufficient evidence.

## Planned artifacts

- `research-plan.md` — question, scope and search matrix.
- `source-register.md` — verified sources and provenance.
- `domain-model.md` — concepts and relationships.
- `product-landscape.md` — implemented products and capabilities.
- `architecture-patterns.md` — observed and inferred architecture patterns.
- `algorithm-comparison.md` — candidate methods and tradeoffs.
- `evidence-matrix.md` — scientific and engineering evidence.
- `bmad-technical-handoff.md` — compact input for BMAD planning.
