# Validation

Validation compares the implemented baseline or candidate with explicit expectations.

## Required distinctions

- Golden Path completion is a product/workflow measure.
- Conditioning and reproducibility are engineering measures.
- Caricature flags are diagnostic until a labeled reference set exists.
- Synthetic observations are not human-grounded evidence.
