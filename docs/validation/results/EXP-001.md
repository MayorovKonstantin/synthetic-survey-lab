# EXP-001 — Paired-persona conditioning result

**Status:** pass  
**Date:** 2026-11-05  
**Method:** `bounded-persona-rules-v1`  
**Test command:** `npm test`

## Fixture

- Two personas in the same confirmed segment.
- `persona-fast`: priority `speed`.
- `persona-careful`: priority `careful`.
- Same questionnaire version: `1`.
- Same seed: `exp-001-fixed`.
- Same question: `q2` (approach).
- Same generation configuration.

## Observed result

The two personas produced different answer distributions for the same question under the same seed and questionnaire version. The expected options were observed predominantly for their corresponding profiles:

- `persona-fast` → `Быстро`.
- `persona-careful` → `Тщательно`.

The evaluation result includes persona IDs, segment ID, question ID, questionnaire version, seed, method, sample sizes, counts, shares and an explicit limitation statement.


The test also calls the evaluation twice with the same completed study and asserts identical serialized results. A changed seed is not used as evidence of conditioning.

## Interpretation

This verifies that the current bounded implementation uses persona profile differences when generating answers. It does not demonstrate that the generated answers match real human respondents, represent a population or support causal inference.
