# EXP-002 — Prompt and answer-option perturbations result

**Status:** diagnostic complete  
**Date:** 2026-11-05  
**Method:** `bounded-persona-rules-v1`  
**Test command:** `npm test`

## Fixture

- Baseline and perturbed studies use the same approved personas.
- Same question ID: `q2`.
- Same sample size.
- Same seed: `exp-002-fixed`.
- Same generation method.
- Controlled perturbation: answer options for `q2` were reversed.

## Observed result

The comparison produced a serializable result with:

- baseline and perturbed run IDs;
- seed and method;
- questionnaire versions;
- question text;
- counts and shares for both runs;
- option-level distribution deltas;
- changed option list;
- limitation statements.

The controlled option-order perturbation changed the observed distribution in the current bounded implementation. This is recorded as a diagnostic signal rather than an automatic product failure.

## Verification

The regression test passed with the full suite:

```text
12 tests passed
0 failed
```

The comparison rejects mismatched seeds, methods, missing questions, missing answers and incomplete persona overlap.

## Interpretation

The current B0 rules method maps some answer behavior to option position. This is an important evaluation property to preserve and measure before comparing with LLM adapters. It does not establish that the method is human-like or that the observed sensitivity is unacceptable in every use case.
