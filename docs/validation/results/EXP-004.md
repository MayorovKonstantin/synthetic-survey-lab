## Implemented contract

`importBenchmarkReference` now validates and normalizes item-level responses while preserving:

- source ID;
- source question ID;
- mapped questionnaire question ID;
- respondent ID;
- response value;
- license metadata.

`evaluateSyntheticAgainstBenchmark` now computes, per question:

- synthetic counts and shares;
- reference counts and shares;
- total variation distance;
- mean total variation distance across questions;
- synthetic run provenance;
- source provenance and limitations.
